## 4. Decisões técnicas

| Item | Escolha | Motivo |
|---|---|---|
| Stack | HTML + CSS + JS puro | Rápido, sem dependência, e o código fica legível pra quem espiar o repo |
| Hospedagem | GitHub Pages | Grátis, HTTPS, integrado ao GitHub (que já é link do currículo) |
| Domínio | `otaviofelix-in.github.io` no início; domínio próprio (ex.: `otaviofelix.dev`) depois | Sem custo pra começar |
| Responsivo | Obrigatório, mobile-first | Recrutador abre no celular |
| Tema | Escuro por padrão + botão claro/escuro | Estética + acessibilidade |
| SEO | `<title>`, meta description, Open Graph (preview bonito ao colar o link no LinkedIn/WhatsApp) | O link vai ser compartilhado |
| Acessibilidade | Contraste AA, navegação por teclado, `alt` em imagens | Detalhe que diferencia |
| Analytics | Opcional (fase 2) | Saber se recrutador abriu |
